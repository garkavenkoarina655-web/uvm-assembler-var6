# УВМ — Вариант №6

Ассемблер и интерпретатор учебной виртуальной машины (УВМ).

**Дисциплина:** Конфигурационное управление  
**РТУ МИРЭА — 2026**

## Язык ассемблера (JSON)

Программа — JSON-массив объектов-команд.

### Команды

#### 1. `load_const` — загрузка константы

```json
{
  "op": "load_const",
  "const": <число 0..4095>,
  "addr": <адрес 0..16777215>
}
```

- Поле B (const) — 12 бит  
- Поле C (addr) — 24 бита  
- Размер команды: 5 байт  
- Результат: значение `const` записывается в память по адресу `addr`

#### 2. `load_mem` — чтение значения из памяти

```json
{
  "op": "load_mem",
  "addr_src": <адрес>,
  "offset": <смещение 0..65535>,
  "addr_dst": <адрес>
}
```

- Поле B (addr_src) — 24 бита  
- Поле C (offset) — 16 бит  
- Поле D (addr_dst) — 24 бита  
- Размер команды: 9 байт  
- Операнд: `memory[memory[addr_src] + offset]`  
- Результат: записывается в `memory[addr_dst]`

#### 3. `store_mem` — запись значения в память

```json
{
  "op": "store_mem",
  "addr_ptr": <адрес>,
  "addr_src": <адрес>
}
```

- Поле B (addr_ptr) — 24 бита  
- Поле C (addr_src) — 24 бита  
- Размер команды: 7 байт  
- Операнд: `memory[addr_src]`  
- Результат: записывается в `memory[memory[addr_ptr]]`

#### 4. `lt` — бинарная операция «меньше» (`<`)

```json
{
  "op": "lt",
  "offset": <смещение 0..65535>,
  "addr_left": <адрес>,
  "addr_dst": <адрес>,
  "addr_right_base": <адрес>
}
```

- Поле B (offset) — 16 бит  
- Поле C (addr_left) — 24 бита  
- Поле D (addr_dst) — 24 бита  
- Поле E (addr_right_base) — 24 бита  
- Размер команды: 12 байт  
- Первый операнд: `memory[addr_left]`  
- Второй операнд: `memory[memory[addr_right_base] + offset]`  
- Результат: `1`, если left < right, иначе `0`; записывается в `memory[addr_dst]`
